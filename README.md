<summary><b>⚡ Quick Reference — SDE Interview Cheat Sheet </b></summary><br>

| Term | Definition | Used In |
|---|---|---|
| **DSA** | Data Structures & Algorithms — core interview screening | Technical rounds |
| **LLD** | Low-Level Design — class design, SOLID principles | Design rounds |

| **REST** | Representational State Transfer — API design style | Backend interviews |
